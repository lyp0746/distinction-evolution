# 方法论说明

本文件说明《区分的演化》所使用的研究方法，供读者评估其可信度。

## 一、证据分级

三级证据标准贯穿全书：

- **A 级**：可独立复现、可由机器验证的结论（如第 12—15 章的相变定理与数值）。
- **B 级**：有公开来源、部分约束、方向可靠的结论（如热核展开的局部系数）。
- **C 级**：概念推理、探索性假设、初步猜想（如 1/3 因子的解释）。

结论强度不超过证据强度：一个 C 级命题永远不会被写成定理。

## 二、概念分级

- **甲**：定义清晰、无歧义。
- **乙**：定义基本清晰，但依赖至少一个未证前提。
- **丙**：概念仍在形成中。

## 三、断言标记

［已知］／［论证］／［假说］／［待验证］四类，与证据等级正交。

## 四、可证伪登记

`docs/preregistration/registry.json` 与 `checkups.csv` 构成一个 append-only 账本。规则：

1. 事前登记；2. 以方向判定；3. 分别报告预测与观察；4. 只追加，永不改写。

`analysis/preregistration_checkup.py` 校验账本结构、日期顺序与命题编号。

## 五、稳健性审计

针对三类"审稿人式"质疑，本书提供了可运行的检验：

- **"你的编码只是贴标签"** → `analysis/pca_fields.py`：对编码矩阵做 PCA，报告有效维度、PC1 份额、平行分析。结果：N_eff≈6.14（K=11），说明统一不是同义反复，但也不是完全同一。
- **"你的阈值公式从哪来"** → `analysis/monte_carlo_sensitivity.py`：对 α、β、k_eff 采样，报告 κ 符号的方向翻转概率与可给出的结论级别。结果：阈值附近方向不稳定，远离阈值方向稳健。
- **"你的数字能复算吗"** → `analysis/graph_phase_transition.py`：协议 V1，确定性复现第 12—15 章全部数值。

## 六、负面结果的处理

- 朴素阈值 `S_c=α/β` 被证明为错 → 正文改用可证的保证衰减阈值（15.3 节）。
- 轨形解释在球面例子上的矛盾 → 正文原样保留（17.5 节）。
- 分离曲率三定义的统一是纲领而非定理 → 逐处标注（9.4、11.4 节）。

## 七、构建与校对

正文以 HTML 源文件为唯一权威来源。`analysis/audit.py` 自动检查术语一致性、公式/图表编号、交叉引用与参考文献。所有构建产物可由 `scripts/build.sh` 重新生成。
