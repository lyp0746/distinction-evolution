# 证据与数据缺口清单

本清单汇总《区分的语法》中无法获得、无法证明或无法验证的内容。一个缺口被写出来，就是一个结果。

## 一、数学证据缺口

| 缺口 | 需要什么才能填上 | 难度 | 当前替代 |
|---|---|---|---|
| 分离曲率定义不统一 | 一个统一定义，使三领域公式为其特例 | 高 | 并列三个定义（9.4 节） |
| 连续情形的公理 4 | Hille–Yosida 型条件 + 区分相容性证明 | 高 | 仅图论验证 |
| 1/3 因子的解释 | 四维计算或轨形构造 | 中 | 三种出路并列（17.3 节） |
| 高维缺口因子 f(n) | 四维 Gauss–Bonnet 计算 | 中 | 猜想 1/(2n+1)（未证） |
| 领域编码的结构保持 | 逐领域证明映射保谱/保度量/保序 | 高 | 仅写出映射（19 章） |
| 离散—连续函子 | 构造保持相变结构的函子 | 很高 | 仅类比（16 章） |
| 主体间性（多智能体） | 多区分系统的耦合理论 | 高 | 仅单系统（10 章） |
