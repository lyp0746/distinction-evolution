# 欢迎补充数据与批评

本纲领的核心是"可被反驳"。它欢迎三类贡献：**数值复现、缺口填补、命题反驳**。

## 一、数值复现

第四部分（第 12—15 章）的所有数字都可以独立复现：

```bash
python analysis/graph_phase_transition.py   # 复现谱与临界耦合
python analysis/pca_fields.py               # 复现编码矩阵 PCA
python analysis/monte_carlo_sensitivity.py  # 复现阈值假说敏感性
```

若你得到与书中不一致的数字，请报告——那说明本书有误。

## 二、缺口填补

本清单中最优先的可执行任务是 **G4（四维缺口因子）**：用符号计算检验 `f(n)=1/(2n+1)` 猜想。这是唯一有明确证伪路线、且不依赖新数学构造的开放问题。若你完成它，请按附录 F 的流程登记。

## 三、命题反驳

下列命题是最容易攻击的（均标注 C 级）：

- **F1**：分离曲率的三个领域定义可统一。
- **G1/G2**：分离结构自然产生 Z/3Z 轨形对称性（球面例子已给出矛盾）。
- **A1/A2**：神经网络激活阈值假说。
- **F5**：15 领域编码可由同一套映射生成。

## 四、如何提交

1. 在 GitHub 仓库开 issue 或 PR。
2. 若涉及预测，请在 `docs/preregistration/checkups.csv` **追加**一行（绝不修改旧行）。
3. 遵守两条纪律：**只追加**、**分别报告预测与观察**。
