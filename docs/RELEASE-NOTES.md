# 修订说明

## 内容构成

- **正文**：六部分、二十二章。第一部分（方法）、第二部分（重建演示）、第三部分（EDS 框架）、第四部分（图上硬核）、第五部分（连续与几何）、第六部分（统一与纲领）。
- **前置**：执行摘要、前言、十分钟速读、阅读地图、术语与记号速查。
- **后置**：结语、后记、附录 A—J。
- **图表**：32 幅 SVG 插图，全部由 `analysis/make_figures.py` 确定性生成（含 4 幅“重建前后”对比图、势能景观、两阶段演化示意、分离度量对比、编码矩阵热力图）。
- **数值**：第四部分的所有数字由 `analysis/graph_phase_transition.py` 从公开定义计算，可独立复现。
- **工程验证（附录 I）**：三个真实运行的实验脚本（LLM 激活探针、轨形缺口、编码保结构），含一个混合结果与两个反例。
- **硬核扩展（附录 J）**：一个推广定理（对称加权不可反转）、一个有向图反转反例、一个恒等式（`κ_info = Var(λ)/2`）、一个证伪（高维缺口 `f(n)=1/(2n+1)`）。

- **形式化（附录 H）**：`formalization/Distinction.lean` 未编译骨架 + 引理分解 + 瓶颈分析。
