# 源材料（provenance）

本目录保存本书的两份原始材料，供读者核对正文的来源与取舍。

## `现代数学抽象与统一.md`

一份关于现代数学抽象、统一与"区分生成结构"的长篇问答记录（62 轮），
覆盖微分形式、生成拓扑、测度论、非标准分析、类型论、复分析、线性代数、
调和分析、图论、概率论、信息论、微分几何等领域，以及"演化区分系统"的雏形。

## `论文撰写.txt`

一份对上述框架的批评与重写记录，包含：
- 对原稿"对话形式 ≠ 学术论文""严格性缺陷""缺少关键数学细节"等问题的批评；
- 一套更严格的公理化重写（六元组、六条公理、若干定理与证明）；
- 关于时间区分、Gauss–Bonnet 因子、Lean 4 形式化的讨论。

## 与本书的关系

本书把这两份材料的**全部内容**重组为六部分、二十二章的学术专著：

- 第一部分（第 1—3 章）：从两份材料的方法论讨论中提炼"压缩"操作与分级制度。
- 第二部分（第 4—7 章）：把材料中的各领域演示整理为四个可检验的案例。
- 第三部分（第 8—11 章）：把材料后期形成的六元组与公理系统整理为框架。
- 第四部分（第 12—15 章）：把材料中唯一严格的部分（图上相变）补全证明并数值复现。
- 第五部分（第 16—18 章）：把 Gauss–Bonnet 因子 1/3 缺口与其线索单列。
- 第六部分（第 19—22 章）：把领域编码、分类、新领域与路线图整理为纲领。

重组的核心原则是：**保留原材料的全部实质内容，但按第 3 章的分级制度逐处标注严格程度**，
并把原文中过度宣称、不可证伪或已被证伪的部分（如朴素的 `S_c=α/β`、轨形解释的球面矛盾）
以原样或修正后的形式写入正文，而非删除。
