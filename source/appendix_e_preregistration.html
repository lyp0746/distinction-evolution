E.5　登记纪律

  1. 事前。所有预测在观察之前写下；本附录的日期为登记日期。
  2. 方向。以方向（符号、序关系）判定，不以精确点值判定。
  3. 只追加。核销以新行追加到 docs/preregistration/checkups.csv；旧行永不修改。
  4. 报告差异。核销时须写明"原始预测／实际观察／是否命中／差异原因"。
  5. 失败也是结果。被证伪的命题以原样保留，并标记为"已证伪"。
  6. 版本控制。本登记簿的"只追加"由 Git 历史强制：核销以新行追加到 docs/preregistration/checkups.csv，旧行不修改；任何修改旧行的提交都能从历史中被检出。脚本 analysis/preregistration_checkup.py 另行校验结构与日期顺序。
E.5.1　维护协议（强制执行） 1. 登记。任何新的假说或开放问题，必须在提出之日添加到相应小节，包含五项：陈述、证据等级、证伪条件、提出日期、提出者。
2. 只追加。一旦登记，只能追加新条目，不能修改或删除旧条目——即使它已被推翻。
3. 证伪标记。若假说被证伪，以新行标记为"★ 已证伪（日期、证伪者、证伪依据）"，旧行原样保留。
4. 双写。核销追加到 docs/preregistration/checkups.csv，本附录同步追加一行。
5. 机器强制。"只追加"由 Git 历史强制：旧行的任何修改都能从 commit history 检出；analysis/preregistration_checkup.py 校验结构与日期顺序。

E.6　开放问题的首步指导

登记一个问题不等于能动手。本节给三个最可操作的问题按"当前卡点 / 第一步 / 预期收益 / 参考文献"展开。所有首步都只依赖公开工具，不需要本书特有的装置。

O12　同伦升维（前沿一） 当前卡点：尚无"有限图区分系统的同伦分类空间"的定义。
第一步：对最简单的两阶段实例（Petersen 图，β 介于 β₁ 与 β₂ 之间）显式写下区分模式构成的群胚，计算其低维同伦群，看是否出现"临界维数跳跃"。
预期收益：若成功，样本从"谱定理应用"升级为"同伦不变量计算"（覆盖代数拓扑）。
参考文献：Lurie, Higher Topos Theory（第 1 章准范畴）；本书第 16 章。
O13　连续区分系统（前沿三） 当前卡点：区分框架没有 Grothendieck 拓扑，无法表达"粘合"。
第一步：在凝聚集范畴中对单个投射有限集 S 定义"区分序列"，验证它是否满足凝聚层的有限联合满射条件。
预期收益：若成功，框架跨过连续—离散鸿沟。
参考文献：Clausen–Scholze, Condensed Mathematics（Lect. 1–2）；本书第 4 章。
O17　独立特征复核（已执行，负面结果） 当前卡点：原 6.14 的 PCA 由词表导出的特征算出，存在循环风险。
第一步（已做）：用 8 个与词表无关的特征对 27 个领域重做 PCA（analysis/independent_features.py）。
结果：有效维度 Neff ≈ 2.9，与猜想 D2 不相容。该实验已于本书完成时执行；本节保留脚本与数据供重复验证。D2 因此被定位为“已被精化的假设”。
救回路径：用真实书目计量数据（nLab/zbMATH/MSC 条目计数、Mathlib 覆盖率）重跑；数据缺口见附录 F。
G7　1/3 的代数根源（前沿二） 当前卡点：三处 1/3 现象（热核归一化、椭圆曲线 3-挠子群、模曲线 X(3) 分支）是否同源尚未计算。
第一步：分别计算三者的 1/3 系数并列表对比；若至少两者的数值机制相同，则"同源"获得一半证据。
预期收益：若一致，缺口获得统一解释；若不一致，"同源"被证伪——两种结果都是成果。
参考文献：本书第 21 章及其文献。
