第 26 章　开放地平线四：量子引力

本章不含定理。它登记"区分的演化"与量子引力（弦论、圈量子引力）之间的可能联系。其中只有一节（26.2 的 Planck 尺度核算）包含可核算的算式，其余是 C 级猜想。更重要的是本章 26.5 节：它明确拒绝把"统一弦论与圈量子引力"写成结果——因为那个主张没有任何可证伪路线。

本章主张 量子引力的两个主要纲领各自处理"连续 vs 离散"：弦论从连续出发，圈量子引力从离散出发。EDS 的精度层级提供了一种同时谈论两者极限的候选语言。本章把它写成 C 级猜想，并给出一个可核算的 Planck 尺度启发式。

26.1　为什么量子引力是"高诱惑、低可证"的方向

量子引力是理论物理最具诱惑力的方向：它承诺统一两大支柱。也正因为如此，它是最容易产生"看起来深刻、实际不可检验"的主张的地方。本章的纪律因此比前几章更严：凡是不能给出可核算步骤或可证伪条件的，一律不写。

26.2　Planck 尺度：一个可核算的启发式（B／乙）

这是本章唯一含算式的一节。它把"观测完备性限制可分辨长度"写成一个可核算的链，得到 Planck 长度作为下界。必须说明：这是量子引力中已知的标准启发式论证，不是本书的原创，也不是一个证明。本书的作用是把它算清楚，并诚实标注等级。

启发式 26.1　可分辨长度的下界 ［启发式，B／乙］ 要用一个探针（例如光子）分辨长度 L：
（1）量子限制：测不准关系给出 δL ~ ℏ/p，要分辨到 L 需 p ~ ℏ/L。
（2）引力限制：该探针能量 E=pc ~ ℏc/L。若这团能量集中在尺度 L 内，其 Schwarzschild 半径为 rs=2GE/c⁴ ~ 2Gℏ/(c³L)。若 rs>L，区域塌缩成黑洞，观测失败。
（3）合并：要求 rs ≤ L，即 2Gℏ/(c³L) ≤ L，得
L ≥ √(2Gℏ/c³) = √2 · ℓP，　ℓP := √(ℏG/c³) ≈ 1.616×10⁻³⁵ m(26.1)
即：能分辨的最小长度约为 Planck 长度（差一个 √2）。
这一节的诚实边界 这是量级估算，不是定理。它的每一步都用了 ~（同阶）而非等式；常数 √2 依赖具体的探针模型；它没有说明时空是否真的离散，只说明"用这种方式测量"存在下界。因此等级是 B（有公开来源、方向可靠），不是 A。它与本书的硬核（第零部分）没有任何逻辑依赖关系。

26.3　圈量子引力：自旋网络作为区分系统的字典（C／丙）

猜想 26.1　自旋网络—区分字典 ［猜想，C／丙］ 在圈量子引力中，量子几何由自旋网络（顶点 + 带自旋标记的边）编码。猜想：存在一个从自旋网络到 EDS 的<定向>映射，使：顶点 ↔ 区分对象、边标记 j ↔ 精度等级、自旋泡沫 ↔ 区分动作序列、重整（recoupling）↔ 精度重标定。
要成为定理，需要：给出映射的显式构造，并证明它保持至少一个非平凡结构（例如观测完备性或谱）。目前没有。
证伪条件：证明不存在这样的保结构映射。

这个字典的动机是真实的（自旋网络确实是有限组合结构，EDS 确实以离散标记为基本对象），但动机不是证明。把它写成"自旋网络就是区分系统"是错误的；正确的说法是"两者共享有限组合的外观，是否共享结构未知"。

26.4　重整化群流与精度序列（C／丙）

猜想 26.2　RG 流—精度序列 ［猜想，C／丙］ 在量子场论中，重整化群（RG）流把紫外（高能）描述连到红外（低能）描述。猜想：RG 流可以写成精度序列 (εUV>…>εIR)，且 RG 不动点对应某个精度等级处的观测完备。
动机：RG 流本身就是一种粗粒化，而 EDS 的精度层级也是一种粗粒化。
证伪条件：构造一个 RG 流，其不动点不对应任何精度等级下的观测完备。
这个猜想可能是同义反复 "RG 流是粗粒化"是标准事实；"精度层级是粗粒化"是 EDS 的定义。因此猜想 26.2 可能只是把同一个词（粗粒化）用了两次。要让它有内容，必须给出一个 EDS 侧的可计算预言（例如：从 EDS 的谱数据预测某个 β 函数的值）。目前没有。［C，可能同义反复］

26.5　明确拒绝：不把"统一弦论与圈量子引力"写成结果

一个诱人的主张是："弦论与圈量子引力是同一个理论在不同精度下的两个极限。"这个主张被写成"通用收缩原理 U1"。本书拒绝把它登记为猜想，理由如下（与第 24.3 节拒绝"难题的区分版"同源）：

U1 不是数学，也不是可检验的物理 （1）没有定义："弦论描述（ε）"与"LQG 描述（ε）"都不是定义清晰的数学对象。
（2）没有极限：没有给出 ε→0 或 ε→∞ 下的收敛含义。
（3）没有证伪路线：无法描述一个观察或计算，其结果能推翻 U1。
因此 U1 不满足本书对"猜想"的最低要求（可证伪），它只是一个愿望。把它写入书中作为"统一"的标题，会同时损害物理的严肃性与本书的分级纪律。

与 26.3/26.4 的区别是：那两条至少给出了"要成为定理需要什么"（映射构造、可计算预言）。U1 连这个都没有。这是本章最重要的一节。

26.7　本章小结

本章把量子引力方向的材料分成了三类：一个可核算的标准启发式（Planck 尺度，B 级）、两条待构造的 C 级猜想（自旋网络字典、RG 流）、以及一个被明确拒绝的主张（U1，不是数学）。如果本书只有一条对物理读者的建议，那就是：不要从 Planck 长度这一个量级估算出发，去宣称两个理论已被统一。前者是可核算的，后者不是。区别就在这里。
