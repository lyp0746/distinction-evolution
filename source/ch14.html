第 14 章　形式决定群：辛、酉、正交，与两次推广

对称双线性形式（上一章）只是「形式」家族的一员。它的两个近邻——反对称（辛）与埃尔米特（酉）——各自决定一个李群，也各自带来一套不同的谱与动力学。这一章把它们并排写出，并把「区分语言」向它们各推广一次，然后诚实说明：能做什么，不能做什么。

本章主张 辛、酉、正交的本质区别，来自所保持的形式的对称性：对称 → 正交，反对称 → 辛，埃尔米特 → 酉。把区分语言推广到辛形式能产出一个可计算的结果；推广到酉形式新意有限。两次推广都只是「换形式」，不是新数学。［已知，B；辛推广的相变为 A］

14.1　统一图景：形式决定群

给定向量空间 V 上的一个非退化形式 B，保持它的变换群就是对应的李群：B(gx,gy)=B(x,y) 对所有 g∈G 成立。对李代数，无穷小版本是 B(Xx,y)+B(x,Xy)=0。

表 14.1　形式决定群
形式类型代数条件李群李代数几何
实对称双线性B(x,y)=B(y,x)正交群 O(n)so(n)欧氏几何
实反对称双线性B(x,y)=−B(y,x)辛群 Sp(2n,R)sp(2n,R)辛几何
复埃尔米特h(x,y)=conj(h(y,x))酉群 U(n)u(n)酉几何
性质：形式—群对应表。等级 B（已知数学）。附录 O 给出速查。

14.2　三种形式的本质区别

正交：对称性。B(x,y)=B(y,x)，二次型 q(x)=B(x,x) 可正、可负、可零。几何含义是长度与角度；保持它的是旋转与反射。李代数 so(n) 是反对称矩阵 XT=−X，维数 n(n−1)/2。

辛：反对称性。ω(x,y)=−ω(y,x)，特别地 ω(x,x)=0 对所有 x 成立。几何含义是面积。李代数 sp(2n,R) 满足 XTJ+JX=0（J 为标准辛矩阵），维数 n(2n+1)。关键：辛形式只能存在于偶数维空间（反对称矩阵的秩必须是偶数）。

酉：复对称性。h(x,y)=conj(h(y,x))，特别地 h(x,x) 是实数，可以正定。几何含义是复长度与复角度。李代数 u(n) 是反埃尔米特矩阵 X*=−X，维数 n²。

14.3　为什么恰好是这三种

在实向量空间上，非退化双线性形式只有两种对称类型：对称与反对称。在复向量空间上，埃尔米特形式最自然（因为它给出实值范数）。这三种形式穷尽了「有限维向量空间上非退化形式」的基本类型。这不是巧合——它来自对合（involution）的分类：

表 14.2　对合的分类
对合形式群
σ²=+1对称正交
σ²=−1反对称辛
σ²=+1（复共轭）埃尔米特酉
性质：分类表。等级 B（已知数学）。

14.4　李代数的统一解释

三种李代数都是导子的特例。给定结合代数 A 与形式 B，定义 g={X∈A : B(Xx,y)+B(x,Xy)=0}——保持 B 的元素的李代数。三种情形的区别只在 B 的对称性：正交是「关于对称形式的反对称」，辛是「关于反对称形式的反对称」，酉是「关于埃尔米特形式的反对称」。三者都是「反对称」在各自形式下的表现。

14.5　谱定理的形式取决于形式的对称性

这是本章与本书主线最相关的一点：谱的形状决定了可能的动力学。

表 14.3　三种形式的谱与动力学
形式谱定理特征值群动力学
对称正交对角化实O(n)衰减／增长
反对称辛对角化纯虚（成对）Sp(2n)振荡
埃尔米特酉对角化实U(n)衰减／增长
性质：谱—动力学对应。等级 B（已知数学）。这就是为什么：拉普拉斯矩阵（对称）有实谱，故第五部分的临界耦合是实数；哈密顿矩阵（反对称）有纯虚谱，故哈密顿系统的频率是实数；埃尔米特矩阵有实谱，故量子力学的可观测量是实数。

本书第五部分（图上样本）是正交情形的谱定理。如果换成辛或酉形式，相变结构会完全不同。

14.6　推广到辛、酉：能做什么，不能做什么

把「对称形式 + 线性 ODE → 实谱 → 两阶段相变」这套样本推广到辛／酉，意味着把「对称形式」换成「反对称形式」或「埃尔米特形式」，看谱结构与相变如何变化。

14.6.1　辛推广：有真实内容

给定图 G=(V,E)，构造相空间 T*V ≅ R2|V|，取哈密顿量

H(q,p) = (1/2)Σv pv² + (1/2)Σ(u,v)(qu−qv)²(14.1)

哈密顿方程 q̇v=pv、ṗv=−(Lq)v 给出 q̈=−Lq——图上的波动方程。线性化 ẋ=Mx，其中 M=[[0,I],[−L,0]]，其特征值为 ±i√λk。因为 L 半正定，所有特征值都是纯虚的——无阻尼系统总是稳定的。

加入阻尼 q̈+γq̇+Lq=0（阻尼波动方程）。模式 k 从振荡变为过阻尼的临界值由拉普拉斯谱决定：

γk = 2√λk,　k=1,…,n(14.2)
辛推广的相变 ［可计算，A／甲］ 随 γ 从 0 增大，模式从低频到高频依次过阻尼：γ<2√λk 欠阻尼振荡，γ=2√λk 临界阻尼，γ>2√λk 过阻尼。这是一个 n 阶段相变。例：超立方体 λk=2k，故 γk=2√(2k)。脚本：analysis/symplectic_probe.py。

它与第五部分的样本是不同动力学的相变：原样本是「区分能力的衰减／增长」，辛版是「振荡模式的稳定性」。这是真正的推广，不是换词。

14.6.2　酉推广：新意有限

在复向量空间上取埃尔米特形式 h(f,g)=Σvconj(f(v))g(v)。无向图的拉普拉斯是实对称的，因此也是埃尔米特的；酉情形的算子仍是 L，谱定理仍给出实谱。结构上与正交情形相同。

唯一的新东西来自磁拉普拉斯 (Lθf)(v)=Σu∼v(f(v)−eiθuvf(u))，它产生 Aharonov–Bohm 型效应（谱依赖于相位）。但这是「加了额外结构」，不是酉推广的自然结果。诚实判断：酉推广本质上是正交情形的复化，不产生本质新东西。

14.7　诚实结论：换形式，不是新数学

  1. 辛推广有真实内容：它给出图上阻尼波动方程的稳定性相变，临界阻尼由拉普拉斯谱决定，可计算、可复现。
  2. 酉推广新意有限：埃尔米特与实对称的谱定理形式相同，复化不产生本质新东西（除非引入磁拉普拉斯）。
  3. 两者都不解决 1/3 缺口：后者是「把不同类型的量当成同一个」的产物，与形式选择无关（见第六部分）。
  4. 这仍然是「换形式」，不是「新数学」：哈密顿力学、辛几何、酉表示都是已有工具；把它们用到图上是有趣的练习，但不构成新理论。
不要把「推广」读成「统一」 本部分到此为止的全部内容，都可以用一句话概括：把已知的二阶结构语言，依次套到几个领域上。它成立、它有用、它可迁移——但它不宣布任何新的数学对象。本书把它称为「一套语言」，而不是「一个理论」，原因就在这里。

14.8　本章小结

形式决定群：对称 → 正交，反对称 → 辛，埃尔米特 → 酉。谱定理的形状取决于形式的对称性，从而决定动力学的类型。区分语言向辛形式推广给出可计算的阻尼波动方程相变A／甲，向酉形式推广新意有限。本部分至此完成：区分被定量化为对称双线性形式，并被放进形式家族。下一部分给出唯一的完全兑现样本。
