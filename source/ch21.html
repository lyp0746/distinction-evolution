第21章　三十六个领域的区分结构

本章主张。把“区分结构”写成三个字段（区分什么、怎么区分、阈值或指标），可以把三十六个领域排进一张表，并分成五族：物理、生命、认知、社会、计算。分级的结论很克制：只有四条的区分判据由标准定理钉住（A 级），多数是 B 级，八条是本书的提议（C 级）。

一位编辑做过一件事：把五十本跨学科著作的核心概念抄成卡片，只写三栏——“区分什么”“怎么区分”“超过多少算不同”。写完他发现自己只剩三十多张不重复的卡片。“大部分书，说的是同一件事的不同版本。”

21.1　导论：一张表能装下什么

表的用处不是“证明统一”，而是暴露空白。三个字段填不满的领域，说明它的区分结构还没有被形式化；三个字段填得太满的领域，说明这张表在硬凑。本章按第 10 章的语法（可比、阈值可传递、可复算）逐条填，填完标级。

21.2　五族与三个字段

物理族的区分对象通常是状态或场，判据来自对称性与守恒；生命族的对象是自我与非我、信号与噪声；认知族的对象是刺激与范畴；社会族的对象是成员、规则与价格；计算族的对象是串、类型与分布。五族的差别不在“难度”，而在阈值从哪里来：物理族的阈值常由常数给定，生命族由进化给定，认知族由生理给定，社会族由制度给定，计算族由定义给定。

21.4　分级的结论

数一遍：A 级 11 条，B 级 18 条，C 级 7 条。这个分布本身就是结论：“区分”这个概念在多数领域是有判据的，但不是有同一个判据的。五族的阈值来源完全不同（常数、进化、生理、制度、定义），因此把三十六条压成一条“普遍规律”是不可能的——能做到的是：每一条都写清三个字段，并标出等级。

21.3b　五族的阈值从哪里来

把阈值来源排成一张表，能看出一个规律：越靠近物理，阈值越“外部”；越靠近社会，阈值越“内部”。

族阈值来源可否被单个实验定住典型争议
物理常数、对称性可以几乎无
生命进化与生理部分可以“适应”怎么定义
认知生理与任务可以（有范式的）任务依赖
社会制度与惯例不能标准之争
计算定义可以（定义一改即变）定义之争

这张表解释了为什么社会族的条目几乎全是 C 级：**阈值本身是争议对象**，而本书的语法要求阈值先固定再比较。这不是方法的缺陷，而是对象的性质——凡阈值未定的领域，任何“普遍规律”都只能以条件句出现。

21.4b　为什么是五族而不是六族：族的分界判据

族不能随便划。本书用一条判据分族：阈值的可协商性。物理族的阈值由常数或对称性钉住，不可协商；生命族由进化与生理钉住，可在个体间浮动；认知族由任务钉住，换任务即换阈值；社会族由制度钉住，可被重新谈判；计算族由定义钉住，改定义即改阈值。

按这条判据，“材料科学”不该独立成族（它的阈值由物理常数与工艺给定，属物理族），“医学诊断”也不必独立成族（阈值可由制度或生理给定，跨生命族与社会族）。判据的好处是它允许一个领域同时属于两族——例如“精神疾病诊断”，生理阈值与社会阈值并存，于是它的条目在表里只能标 C 级（第 21 与第 25 条的合并）。

跨族案例两套阈值冲突时的表现本书的处置
精神疾病诊断生理 / 制度同一人两套结论C 级，条件句
教育评估认知 / 制度测得出但不敢用C 级，条件句
算法公平计算 / 社会定义一变结论反转C 级，条件句
气候临界点物理 / 社会物理阈值可算，政策阈值不可算分两条登记

四个案例的共同点：跨族的条目不能合并成一个等级，只能拆成两条、各标各的。这也是第 3 章“等级跟着测量条件走”的直接推论。

21.5　反例：覆盖表的三种虚假繁荣

  • 凑数：把同一领域拆成三条（如“价格信号”“价差”“议价”），表面上三十六个，实际三十个。
  • 借级：把 B 级写成 A 级，靠引用一个标准定理，而那条定理只覆盖领域的一小块。
  • 空洞：三个字段里“阈值或指标”一栏写成“视情况而定”，等于没填。

三种虚假繁荣的解毒剂是同一条：每个条目的第三栏必须能被一个具体的量或一条具体的定理填满。填不满的，就只能留在 C 级——这不是失败，是诚实的定位。

21.6　本章小结

三十六个领域、五族、三个字段、三级。A 级 11、B 级 18、C 级 7。表的价值在于暴露空白：C 级的七条正是下一步要形式化的对象。第 22 章挑三条 B 级去做“可复算的迁移”，看它们能不能升级。

一句话带走：一张覆盖表最有用的时候，是它露出十七个空格。

21.5b　覆盖表的维护规则

表会过期：领域会变，判据会变，条目会合并或拆分。维护规则四条，写在表前：

  1. 只增不删：过时的条目保留并标“已过期”，不删除（与附录 D 同一纪律）。
  2. 一改必标日期：任何等级变化都写日期与理由。
  3. 跨族条目拆成两行：如“精神疾病诊断”拆成生理阈值与社会阈值两行（第 21.4b 节）。
  4. 不追新词：新领域要进表，必须先填满三个字段；填不满的，先放附录 D 的未执行项。

四条规则的成本很低，但它们决定了这张表是“知识”还是“清单”。清单会随潮流变形，知识只能被推翻。本书希望这张表属于后者。

21.10　把三十六条压成四类的判别树

三十六条太细，用一棵判别树可以三步定位任何一条属于哪类。

  1. 问阈值的来源：常数/对称性 → 物理族；进化/生理 → 生命族；任务/范式 → 认知族；制度/惯例 → 社会族；定义 → 计算族。
  2. 问阈值能否被独立测量：能 → 至少 B 级；不能 → C 级（除非有标准定理直接钉住）。
  3. 问判据是否由标准定理给出：是 → A 级。

B（阈值可测）18神经编码、生态位、价格信号、复杂度类
C（阈值争议）7微生物组、价值判断、身份边界、法律涵摄

三步判别树的价值：它把“为什么这条是 C 级”变成一个可回答的问题（第 2 步失败），而不是一个态度。任何人不同意某个等级，只需指出第 2 步的证据——争论因此有了落点。

21.11　覆盖表的三次修订记录

这张表不是一次写成的。三次修订的动机各不相同，记下来，便于读者判断它的可信度。

修订动机变化教训
第一版（27 条）想“尽量多”三条属同一领域，实为凑数数量不是覆盖面
第二版（36 条）按五族分类后合并重复删除 3、新增 12分类先于计数
第三版（加两列）发现无法判断“哪条更硬”加“失效条件”“复算方式”可裁决性要写进表里

三次修订的共同点：每一次都是因为“表里有一列填不出来”才改的。第一版填不出“为什么这条算一个领域”，第二版填不出“为什么这条和那条不是重复”，第三版填不出“凭什么说它硬”。

这条经验对任何“覆盖表”类工作都适用：先想清楚要填哪几列，再决定收多少条。列决定表的性质，条数只是它的长度。本书最终停在 36×5（五列：对象、动作、阈值、失效条件、复算方式），其中第五列是最难填、也最有用的一列。
