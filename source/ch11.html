第11章　区分：语言的起点

婴儿先学会的不是“狗”，是“妈妈”和“不是妈妈”。一切认识，都从划一道线开始。

本书的核心词只有一个：区分。这一章把它写成一套语言的最基本词汇——区分动作、观测、不可区分关系与精度层级——并说明三者如何互为对偶。它同时写下本书最重要的一次删除：初稿里与「区分」并列的另外两个原语（曲率、演化），不再作为独立对象。

本章主张 「区分」不是模糊的直觉，而可以被形式化：一族把对象分开的操作，配上观测与不可区分关系。但「区分」只是一个线索；它的定量内容将完全落在下一章的双线性形式上。本章属于语言层（C），不含定理。［描述，C／丙］

11.1　导论：从三个原语到两个更基本的词

本书的初稿曾把框架写成三个并列的原语：区分（对象如何被分开）、曲率（区分能力随精度或时间的增长率）、演化（区分结构随时间的运动）。进一步的分析给出一个更简洁、也更一般的读法：这三个原语收敛到同一个结构。这不是失去，而是一次归并——两个原语被证明是同一个对象的两个侧面。

  • 曲率是形式谱的一个侧写。离散的 κ_info=Var(λ)/2 是拉普拉斯谱分布的一个量，连续热核展开的 a₁=R/6 是局部分析系数；二者是类型不同的两个量（平坦二维环面 R=0，而任意网格的离散谱方差恒为 2.000，脚本 analysis/kappa_type_mismatch.py）。看清这一点，等于把一个含糊的「统一曲率」换成了一个精确的问题：哪个谱量在什么意义下可迁移。
  • 演化是形式谱上的线性 ODE。图上的「演化」就是对称双线性形式（拉普拉斯）谱上的线性常微分方程——它属于已知线性代数，因此不需要作为独立原语。把演化归并入形式，让动力学自动继承谱定理与变分原理。

归并之后，语言更简洁也更有力：「区分」的定量内容就是一个对称双线性形式。「两个对象如何彼此区分」对应 B(x,y)；「一个对象与自身的区分／波动」对应二次型 q(x)=B(x,x)。三个原语收敛成一个代数结构——这正是下一章的主题，也是全书最坚实的一处「统一」。

这次归并留下了什么 初稿中关于「分离曲率」的定理与章节没有被删除，而是被登记为归并记录（附录 可证伪登记簿 的 R1—R4）。保留它们的理由是本书的方法论：一次修正的价值，在于把边界画清楚。读者若在某处仍看到「分离曲率」这个词，请把它读作「拉普拉斯谱方差」或「一个已被归并的命名」。

11.2　区分动作族

定义 11.1　区分动作族 设 X 是一个对象集合。一个区分动作族 D 是 X 的一族子集（或 X 上的一族函数），满足：
（D1）边界条件：∅, X ∈ D；
（D2）交封闭：若 {Di}i∈I ⊆ D，则 ⋂i Di ∈ D；
（D3）精化存在：对任意 D₁,D₂∈D，存在 D′∈D 使得 ∅≠D′⊆D₁∩D₂。
D 中的元素称为区分动作。

与拓扑的并封闭不同，这里要求交封闭与精化存在。直觉上：区分动作是「缩小的透镜」，你可以把它们叠在一起看得更细（交），但不能指望任意并仍在族内（把两个不同透镜的视野直接相加没有意义）。

例子 图论：DG={VS: S⊆V}（顶点子集族）。
拓扑：任何拓扑的子基。
代数：某个群的全部子群。
信息论：一族检验函数。
不同领域的「区分」差别很大，但都满足 D1—D3。

11.3　观测泛函

定义 11.2　观测泛函 观测泛函 O: D → [0,1]X 把每个区分动作映为一族观测值，满足：
（O1）单调性：D₁⊆D₂ ⇒ O(D₁)(x) ≤ O(D₂)(x)；
（O2）边界条件：O(∅)(x)=0，O(X)(x)=1；
（O3）右连续性：O(·)(x) 关于包含偏序右连续。

观测值 O(D)(x)∈[0,1] 表示「在区分动作 D 下，点 x 的可区分／可观测程度」。单调性说的是：更大的区分动作（更粗的透镜）给出更确定的观测。

11.4　不可区分关系与精度层级

定义 11.3　精度等价关系族 对每个精度参数 α∈(0,∞)，定义等价关系 ∼α，满足：
（E1）精度单调：α₁<α₂ 且 x∼α₂y ⇒ x∼α₁y（精度越高，区分越细）；
（E2）完备性：x∼0y ⇔ O(D)(x)=O(D)(y) 对所有 D 成立；
（E3）分离能力：α(x,y) := inf{α : x≁αy} 度量 x,y 的区分难度。

这套关系把「不可区分」变成一个有刻度的概念。两个对象不是简单地「一样」或「不一样」，而是在多大精度下才能被分开。

公理 11.1　观测完备性 ∀x,y∈X: O(D)(x)=O(D)(y) 对所有 D∈D 成立 ⇔ x∼0y。
即：若两点在所有区分动作下观测相同，则它们在精度 0 下不可区分；反之亦然。

这条对偶保证三个词汇不是各自独立定义的，而是同一结构的三种投影。在不同领域，它表现为不同的熟悉事实：拓扑学里「两点有相同的邻域当且仅当局部不可分」；代数里「两个元素所有特征值相同当且仅当相似」；概率论里「两个事件在所有检验下分布相同当且仅当几乎总会相等」。

11.5　从「区分」到「结构」：本章的出口

到这里，语言还只停在「分开」这个动作上，没有回答一个关键问题：被区分出来的东西，如何度量？如果只有集合与开集，我们能说「这两点不同」，却不能说「这两点的关联有多强」「一个取值对整体的影响有多大」。

答案是：给对象空间一个对称双线性形式。它把「区分」从定性变成定量——这是从语言（怎么说话）到结构（说什么）的一步。下一章给出它的最简形式：二次型。

为什么这一步不是「引入新原语」 对称双线性形式不是又一个被发明出来的对象，而是「区分」本身被写成一个函数后的自然产物：一旦你要把「两个对象彼此的区分」变成一个可以在不同领域比较、相加、求和的量，你得到的就是双线性形式。本部分余下三章只做一件事：把这件事写清楚。
人的尺度

一个学琴的孩子问：“为什么同样的音，老师弹出来是音乐，我弹出来是练习？”老师说：“因为你还在找音，我已经在找句子。”区分是起点，但不是终点：先分开，再连起来，才成句。

11.6　本章小结

本章把「区分」写成语言的起点词汇：区分动作、观测、不可区分关系与精度层级，三者由观测完备性对偶地绑在一起。它同时归并了初稿中「曲率」与「演化」两个原语，把问题推向下一章——区分结构的定量内容是对称双线性形式。

反例。"区分是语言的起点"这条主张有一个反例：许多动物能在不显式区分的情况下做出适应行为（习惯化）。这说明区分是"可陈述知识"的起点，不一定是"行为"的起点。

一句话带走：区分是语言的起点；说不清区别，就说不上知道。
