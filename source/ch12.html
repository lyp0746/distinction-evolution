第 12 章　二次型：双线性形式的「对角线」

上一章把「区分」写成语言的基本词。这一章给出它的定量内容：二次型——一个向量与自身之「区分」的度量。二次型背后是一个双线性形式，它是双线性形式在对角线上的取值；反过来，知道「自关联」，就能用极化恒等式恢复「互关联」。

本章主张 二次型、双线性形式、协方差、Hessian、图拉普拉斯、内积——这些名字背后是同一个代数结构：向量空间上的对称双线性形式。本章不证明新定理，只把这套语言写清楚；唯一保留的刚性结果是一个精确恒等式（定理 12.1）。［已知，B；定理 12.1 为 A］

12.1　二次型的定义

一个二次型是形如

Q(x) = Σi,j aij xi xj = xTA x(12.1)

的齐次二次多项式，其中 A 是对称矩阵。它只含平方项与交叉项，不含一次项与常数项。

关键：二次型是一个向量 x 的函数，但它背后藏着一个双线性形式

B(x,y) = xTA y(12.2)

对两个向量 x,y 分别线性。二次型是双线性形式在「对角线」上的取值：Q(x)=B(x,x)。

12.2　极化恒等式：知道自关联，就能恢复互关联

在实数域上，对称双线性形式与二次型一一对应。给定 B，定义 Q(x)=B(x,x)；反过来，给定 Q，可以用极化恒等式恢复 B：

B(x,y) = (1/2)[ Q(x+y) − Q(x) − Q(y) ](12.3)
一句话 双线性形式是「两个变量的交互」，二次型是「一个变量自身的波动」。两者是同一数学对象的两种呈现：全矩阵与对角线。［已知，B］

12.3　协方差：概率论中的双线性形式

协方差是双线性形式：Cov(X,Y)=E[(X−EX)(Y−EY)]；方差是二次型：Var(X)=Cov(X,X)。对随机向量 X=(X₁,…,Xₙ)，协方差矩阵 Σ 定义二次型

Q(a) = aTΣa = Var(aTX)(12.4)

协方差矩阵就是二次型的矩阵。方差是二次型在坐标轴上的对角值，协方差是交叉项。几个直接推论：

  • 马氏距离：d²(x,μ)=(x−μ)TΣ−1(x−μ) 是二次型。
  • 高斯分布：密度 ∝ exp(−(1/2)(x−μ)TΣ−1(x−μ))，指数部分是二次型。
  • PCA：对 Σ 做特征值分解，就是把二次型化为标准型（主轴化）。

12.4　Hessian：优化中的双线性形式

对多元函数 f: Rn→R，二阶泰勒展开

f(x₀+h) ≈ f(x₀) + ∇f(x₀)Th + (1/2) hTHf(x₀) h(12.5)

二阶项 hTHfh 是二次型，矩阵是 Hessian。Hessian 本身是双线性形式 Hf(v,w)=vTHfw。正定 ⇔ 局部极小；负定 ⇔ 局部极大；不定 ⇔ 鞍点。优化中的曲率，就是二次型的正定性。

12.5　矩、累积量与高次型

二阶导数是双线性形式，二阶泰勒项是二次型。推广：n 阶导数是 n 线性形式，限制到对角线得到 n 次型；泰勒系数 f(n)(a)/n! 对应 n 次型，矩 E[Xn] 对应 n 次型的系数。

矩生成函数 M(t)=E[etX]=Σ E[Xn]tn/n! 的二阶项 E[X²]t²/2 对应二次型，方差是它的中心化版本。累积量生成函数 log M(t) 的二阶项直接是方差，混合二阶项是协方差——累积量的二阶部分就是二次型。

12.6　图拉普拉斯二次型与拉普拉斯谱方差

图拉普拉斯矩阵 L 定义二次型

xTL x = Σ(u,v)∈E (xu − xv)²(12.6)

这是图上的能量，度量相邻顶点取值的差异。它是半正定二次型；谱分解后特征值是二次型在单位球上的驻值；Rayleigh 商 R(x)=xTLx / xTx 是二次型与范数之比；第五部分的临界耦合 β₁=α/λn、β₂=α/λ₂ 完全由这个二次型的谱决定。本书唯一的完全兑现样本，本质上就是这个二次型的谱分析。

定义 12.1　拉普拉斯谱方差（旧称「拉普拉斯谱方差 κ_info」） 设 G 是 n 顶点图，L 为拉普拉斯矩阵。取热核的密度矩阵 ρ(t)=e−tL/Z(t)、Z(t)=tr(e−tL) 与 von Neumann 熵 S(t)=−tr(ρ(t) log ρ(t))。定义 κ_info(G) := −(1/2) S″(0⁺)。
定理 12.1　拉普拉斯谱方差恒等式 ［定理，A／甲］ 对任意有限图，
κ_info(G) = (1/2) Var(λk) = (1/2)[ (1/n)Σkλk² − ((1/n)Σkλk)² ](12.7)
即热核熵的二阶变分等于拉普拉斯谱方差的一半，且对 n≥2 恒有 κ_info>0。

推导。由 ρ 的特征值为 pk=e−tλk/Z，得 S(t)=log Z + tA/Z，其中 A(t)=Σkλke−tλk。直接求导：S′(t)=t(A/Z)′，故 S′(0)=0，且 S″(0)=(A′Z−AZ′)/Z²|0=(−nΣλ²+(Σλ)²)/n²=−Var(λ)，故 κ_info=−S″(0)/2=Var(λ)/2。∎

12.7　本章小结

二次型是双线性形式在对角线上的取值；极化恒等式让它与双线性形式一一对应。协方差、Hessian、图拉普拉斯都是它的实例。在图上，热核熵的二阶变分给出一个精确的谱方差恒等式（定理 12.1）——它是本书最坚硬的结果之一，但不是几何曲率。下一章把这个结构抽象为一般对象：向量空间上的对称双线性形式。
