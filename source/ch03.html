第3章　证据等级：A／B／C 与四类断言

本章主张。每一条断言都要带两个标签：证据等级（A 官方可复现／B 稳定公开估计／C 稀疏·构造·思辨）与断言类型（已知／论证／假说／待验证）。并且守一条硬规矩：结论强度不超过证据强度。

体检报告上有一行小字：“参考区间基于本市 2019 年抽样。”大夫指着它说：“同一个数字，有出处和没出处，是两件事。”一套理论也一样。

3.1　导论：为什么书要先谈证据

读者对“统一”类著作的合理怀疑是：说得太大了。要回答这个怀疑，不能靠“我很谨慎”的姿态，只能靠可检查的标签。本章给出标签系统，它在本系列所有著作中共用，因此读者可以横向比较：哪一本的哪一条结论站在 A 级上，哪一条只是 C 级联想。

3.2　三级证据

定义 3.1　三级证据（A／B／C）
  • A 级：可被第三方按公开步骤复现。包括：定理与完整证明、可运行的脚本及其输出、官方统计。
  • B 级：来自稳定、可查的公开估计，但复现依赖外部数据或专业判断（如文献中的相关系数、领域共识区间）。
  • C 级：稀疏、构造性或思辨性的材料：单例、类比、思想实验、尚未被独立验证的构造。

三级之间不是“可信／不太可信”的连续谱，而是三种不同的证明方式：A 靠重演，B 靠溯源，C 靠标注。把 C 级材料写成 B 级的语气，是最常见的失分。

3.3　四类断言

断言类型它在说什么读者该问什么本书的标记

论证本书给出的推理链，可逐行检查哪一步用了未证的假设？〔论证，A／乙〕

表 3.1　四类断言　类型与等级是两个维度，不能互相替代：一条“论证”可以是 B 级（依赖外部数据），一条“已知”也可以是 C 级（领域内只有孤例）。

3.4　结论强度不超过证据强度

这条规矩的具体含义是：你不能用 A 级的证据去支撑 C 级的结论，也不能用 C 级的证据去支撑 A 级的语气。前者是把小样本当成普遍规律，后者是把猜想写成定律。它约束的是句子，不是人：同一个人可以在第 15 章写 A 级定理，在第 21 章写 C 级覆盖表，只要两处都标对。

它还有一个更实用的版本：一条结论的下游，只能比它自己更弱。从 A 级定理推出的推论仍是 A 级（因为证明可重演）；从 C 级类比推出的应用仍是 C 级（因为类比的断裂没有被排除）。这条规则会在第 23 章反复出现。

3.4b　同一条结论在两个领域里的等级不同

“临界慢化”（临界点附近系统恢复变慢）在统计物理里是 A 级：有精确解、有数值、有可重跑的模拟。搬到生态学，它立刻降为 B 级：数据是观测的，恢复时间的测量依赖模型设定。再搬到社会科学，它只剩 C 级：连“恢复”都难以定义。

这不是学科歧视，而是测量条件的差异。同一条数学命题（慢化随临界指数发散）在三个领域里真值相同，但“能被复现到什么程度”不同。于是本书的规矩是：等级跟着测量条件走，不跟着命题走。这也解释了为什么第 21 章的覆盖表里，同一个概念在不同条目上会标不同等级。

3.5b　把“可复算”写成一个操作定义

“可复算”有三种强度，本书只要求中间那种。强：任何人用同一份数据、同一段代码，得到完全相同的数字（浮点级别）。中：任何人用同一份数据，得到在声明的容差内一致的数字（例如第 19 章表 19.1 的 0.1%）。弱：任何人用同类方法，得到方向一致的结论。

三者对应三种不同的失败方式：强标准失败于环境差异（库版本），中标准失败于容差未声明，弱标准失败于“方向一致”太容易满足。本书的做法是：A 级要求“中”，并把容差写进结论；B 级只要求“弱”，但必须写出数据来源；C 级不要求复算，但要求写出反例条件。这条分层让“可复算”不再是一句态度，而是一个可以核对的承诺。

3.5　反例：如何把 C 级写成 A 级

有四种常见手法，每一种都在真实文本里出现过：

  • 借光：“研究表明……”——不写是哪一项研究。借的是科学的整体信用。
  • 抽样升格：拿三个案例的共性，写成“普遍规律”。
  • 术语护甲：用“本质上”“在某种意义上”把可检验命题变成不可检验命题。
  • 数字装饰：给一个 C 级判断配一位小数（“约 0.73 的相关性”），让读者以为它被测过。

这四种手法有一个共同的解毒剂：要求一个具体的反例。凡是给不出“什么情况算它错”的句子，无论配了多少数字，都只能算 C 级。

3.6　本章小结

证据有三级（重演／溯源／标注），断言有四类（已知／论证／假说／待验证），标签必须成对出现。规矩只有一条：结论强度不超过证据强度。本书后面每一次“这可以迁移到别的领域”的说法，都要先过这一关；过不了的，进第 21 章的覆盖表并标 C。

一句话带走：给一个判断配数字之前，先给它配一个反例；配不出反例的判断，数字只是装饰。

3.6b　一次历史上的分级事故：塞麦尔维斯

1847 年，塞麦尔维斯发现洗手能降低产褥热死亡率，从约 10% 降到约 1%–2%。这是 A 级证据——可重复、有对照、有数字。但当时的医学共同体拒绝它，理由是“理论不通”。这就是分级事故：证据是 A 级，接受的判据却是 C 级（讲得通）。

反过来也有另一种事故：一个 C 级的机制故事（“瘴气致病”）因为讲得通而被当成 A 级，压住了 A 级数据几十年。两次事故的方向相反，病因相同——把“讲得通”与“可复现”混成一条判据。第 3.2 节把两者分开写，就是为了避免这类事故。

3.7　分级与统计功效：一个可算的例子

为什么“样本量”会改变证据等级？因为功效是可算的。要在双侧检验中检出效应量 d，显著水平 α=0.05、功效 1−β=0.8，所需样本量近似为

n ≈ 16/d²(3.1)

于是 d=0.5 需要约 64 例，d=0.2 需要约 400 例。若一项研究只有 30 例却报告 d=0.2 显著，那它的“显著”在数学上就不可能稳定复现——这不是方法学意见，是算术。本书把这类结论标 B 而不是 A，理由就在这里。

这条式子的用处有一个边界：它只适用于“有明确效应量”的情形。凡效应量本身不可定义（例如“制度是否更有效”），d 就无从谈起，功效分析也就失效——此时只能退回定性判据（第 3.5b 节的“中标准”）。分级不是更严格的判断，它只是把“能不能算”写在了明处。

3.8　给专家的注：为什么分级要写成四类断言

三级证据（A/B/C）回答“证据有多硬”，四类断言（已知/论证/假说/待验证）回答“这句话在做什么”。两者交叉，才不至于把“硬证据支持的软主张”误读成“软证据支持的硬主张”。

交叉例子误读风险
A 级证据 + 假说两阶段相变的数值成立，但“社会系统也如此”是假说把假说当定理
C 级证据 + 已知“熵增”在孤立系统里是已知，但“社会熵增”只有类比把类比当已知
A 级 + 待验证定理已证，但“它是否适用于某类网络”未验证把定理当普适

三种误读的共同点是：它们都发生在“从证据跳到断言”的那一步，而不是发生在证据本身。所以本书把两者写成两个独立标签，而不是一个总分。

【给专家的注】分级与统计功效是同一件事的两面：功效公式 n≈16/d² 说明「A 级」在数学上等价于「样本足以稳定复现」。凡不肯给样本量的 A 级，都要打折。

3.9　三次分级事故

历史上三次著名的分级事故，方向各不相同，病因相同。

塞麦尔维斯（1847）：A 级数据被 C 级惯例压住。死亡率从 10% 降到 2%，但“讲不通”被当作否决理由。病因：把“讲得通”当判据。

营养学的“脂肪—心脏病”之争（1950s—）：B 级证据被 A 级语气使用。观察性研究给出相关性，被写成因果建议，几十年后仍在修正。病因：把 B 级升成 A 级。

心理学可重复性危机（2015—）：A 级证据在重复中崩塌。大量“显著”结果在更大样本下失效，原因是功效不足与发表偏倚。病因：把 n 太小的 A 当成 A。

三例对应第 3 章的三条纪律：讲得通不算证据、B 级不能升格、A 级要写样本量与功效。三条都写在纸面上，事故仍然发生——这说明分级不是知识问题，是制度问题，所以本书把它写成“标签必须成对出现”的可检查格式。
