第3章　证据等级：A／B／C 与四类断言

本章主张。每一条断言都要带两个标签：证据等级（A 官方可复现／B 稳定公开估计／C 稀疏·构造·思辨）与断言类型（已知／论证／假说／待验证）。并且守一条硬规矩：结论强度不超过证据强度。

体检报告上有一行小字：“参考区间基于本市 2019 年抽样。”大夫指着它说：“同一个数字，有出处和没出处，是两件事。”一套理论也一样。

3.1　导论：为什么书要先谈证据

读者对“统一”类著作的合理怀疑是：说得太大了。要回答这个怀疑，不能靠“我很谨慎”的姿态，只能靠可检查的标签。本章给出标签系统，它在本系列所有著作中共用，因此读者可以横向比较：哪一本的哪一条结论站在 A 级上，哪一条只是 C 级联想。

3.2　三级证据

定义 3.1　三级证据（A／B／C）
  • A 级：可被第三方按公开步骤复现。包括：定理与完整证明、可运行的脚本及其输出、官方统计。
  • B 级：来自稳定、可查的公开估计，但复现依赖外部数据或专业判断（如文献中的相关系数、领域共识区间）。
  • C 级：稀疏、构造性或思辨性的材料：单例、类比、思想实验、尚未被独立验证的构造。

三级之间不是“可信／不太可信”的连续谱，而是三种不同的证明方式：A 靠重演，B 靠溯源，C 靠标注。把 C 级材料写成 B 级的语气，是最常见的失分。

3.4　结论强度不超过证据强度

这条规矩的具体含义是：你不能用 A 级的证据去支撑 C 级的结论，也不能用 C 级的证据去支撑 A 级的语气。前者是把小样本当成普遍规律，后者是把猜想写成定律。它约束的是句子，不是人：同一个人可以在第 15 章写 A 级定理，在第 21 章写 C 级覆盖表，只要两处都标对。

它还有一个更实用的版本：一条结论的下游，只能比它自己更弱。从 A 级定理推出的推论仍是 A 级（因为证明可重演）；从 C 级类比推出的应用仍是 C 级（因为类比的断裂没有被排除）。这条规则会在第 23 章反复出现。

3.4b　同一条结论在两个领域里的等级不同

“临界慢化”（临界点附近系统恢复变慢）在统计物理里是 A 级：有精确解、有数值、有可重跑的模拟。搬到生态学，它立刻降为 B 级：数据是观测的，恢复时间的测量依赖模型设定。再搬到社会科学，它只剩 C 级：连“恢复”都难以定义。

这不是学科歧视，而是测量条件的差异。同一条数学命题（慢化随临界指数发散）在三个领域里真值相同，但“能被复现到什么程度”不同。于是本书的规矩是：等级跟着测量条件走，不跟着命题走。这也解释了为什么第 21 章的覆盖表里，同一个概念在不同条目上会标不同等级。

3.5　反例：如何把 C 级写成 A 级

有四种常见手法，每一种都在真实文本里出现过：

  • 借光：“研究表明……”——不写是哪一项研究。借的是科学的整体信用。
  • 抽样升格：拿三个案例的共性，写成“普遍规律”。
  • 术语护甲：用“本质上”“在某种意义上”把可检验命题变成不可检验命题。
  • 数字装饰：给一个 C 级判断配一位小数（“约 0.73 的相关性”），让读者以为它被测过。

这四种手法有一个共同的解毒剂：要求一个具体的反例。凡是给不出“什么情况算它错”的句子，无论配了多少数字，都只能算 C 级。

3.6　本章小结

证据有三级（重演／溯源／标注），断言有四类（已知／论证／假说／待验证），标签必须成对出现。规矩只有一条：结论强度不超过证据强度。本书后面每一次“这可以迁移到别的领域”的说法，都要先过这一关；过不了的，进第 21 章的覆盖表并标 C。

一句话带走：给一个判断配数字之前，先给它配一个反例；配不出反例的判断，数字只是装饰。
