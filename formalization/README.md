# Lean 4 形式化路线图

本目录保存《区分的演化》第四部分（图上演化区分系统与临界耦合定理）的 Lean 4 形式化**骨架**与路线图。它回应一条具体的批评：**书里把"用 Lean 4 形式化定理 12.1"列为短期任务，却没有给出任何形式化产物。** 本目录是这个缺口的第一次交付。

## 为什么值得形式化

定理 12.1 的证明只用实对称矩阵谱定理与线性 ODE。这意味着形式化**不依赖**任何本书特有的、未定义的框架——它是标准数学。一旦通过，它就给整个纲领提供了一块机器可验证的基石。

## 建议的 PR 顺序（由易到难）

1. **`intermediate_phase_nonempty`（低难度，可立即完成）**
   纯代数：`β₁ = α/λₙ < α/λ₂ = β₂`，由 `α > 0` 与 `λ₂ < λₙ` 推出。
   这是第一个能真正编译通过的引理。

2. **`laplacian_symm`（低难度）**
   拉普拉斯矩阵的对称性，纯组合簿记。

3. **`evolution_is_solution`（中难度）**
   证明 `D(t) = exp(tM)D₀` 满足 `Ḋ = MD`。Mathlib 有矩阵指数与导数的接口，但需要把它接到"矩阵乘向量"的 `ContinuousLinearMap` 上。

4. **`spectral_decomposition`（高难度，最关键）**
   把实对称矩阵的谱定理与特征值排序 `0 = λ₁ < λ₂ ≤ ⋯ ≤ λₙ` 拼到一起。Mathlib 的相关结果分散在若干模块，这是本形式化**最重**的一步。建议先做一个只含矩阵、不含 ODE 的独立引理文件。

5. **`critical_coupling`（高难度）**
   在三情形下做符号分析。本质上是对有限个实数列提取主项，配合指数衰减/增长的 `Filter.Tendsto` 引理。

## 关键瓶颈

| 瓶颈 | 说明 | 建议 |
|---|---|---|
| 谱定理的 API | Mathlib 中实对称矩阵谱定理分散在多个模块 | 先做最小版本：只需"存在正交特征基" |
| 矩阵指数与 ODE 的衔接 | `exp(tM)D₀` 的导数需要 `ContinuousLinearMap` 接口 | 参考 Mathlib 中 `Matrix.exp` 的现成引理 |
| "最大时间区间" | 定理原本陈述"定义在最大时间区间上"；在图论情形其实是全体 `ℝ`，可去掉该表述以简化 | 在形式化版本中直接断言对所有 `t : ℝ` 成立 |
| 一般初值 | `cₙ ≠ 0` 是零测度条件 | 形式化时显式假设"最高频投影非零"，或证明对 a.e. 初值成立 |
| 连通性 | `λ₂ > 0 ⟺ G 连通` | Mathlib 有图论连通性；映射到谱需要一条引理 |

## 与本书承诺的关系

本书第 22.6 节把形式化列为短期任务，并标注"难度中等"。本目录把这条承诺从**标签**变成**可执行的缺口清单**：哪些引理、什么顺序、卡在哪里。如果本目录的骨架被 Lean 社区接手并编译通过，第 22.6 节的状态可以从"承诺"升级为"已完成"——在那之前，它仍然是**未兑现的承诺**，本目录不掩饰这一点。
