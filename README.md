# 区分的语言

> 区分如何生成空间、形式与谱——七条定理、三十六个领域与一次连续极限
>
> **DOI**：10.5281/zenodo.23930312　·　概念 DOI：10.5281/zenodo.23345012　·　283 页 / 5 部分 / 25 章

本书的贡献是一次归并。作者初稿把框架写成三个原语——区分、曲率、演化；进一步的分析把它们收敛为两个更基本的词：<b>区分</b>与<b>对称双线性形式（二次型）</b>。「曲率」是形式谱的一个侧写，「演化」是形式谱上的线性 ODE。归并之后，语言更简洁、也更一般：协方差、Hessian、图拉普拉斯、内积、黎曼度量都是同一个结构的实例，谱定理、变分原理、极化恒等式是它自带的三套工具。本书因此从“一个数学框架”转为<b>一套语言描述</b>：以“区分”为线索，把不同领域里重复出现的同一件事写成可描述、可对照的语言。全书唯一完全严格的部分是图拉普拉斯二次型的谱分析——两阶段相变定理，临界耦合由拉普拉斯谱决定，可证明、可计算、可复现；本书明确它是标准数学（换形式），不是新理论。它还报告两次“换形式”的推广：辛推广给出可计算的阻尼波动方程相变，酉推广新意有限。评价这套语言的标准与理论不同：不是“今天证了多少定理”，而是它是否被采用、是否压缩了记号、是否让跨领域迁移变得可读（第 26.4.1 节）。卷首《总纲　现实中不存在无限》把这套语言的地基写在最前面：无限只作为极限，不作为现实系统的属性；有限的分辨率预算，是 1/3 缺口与两阶段相变共同的起点。

## 本版（2026-11-04）

三类修改，均不动编号：

1. **新增七节**：`1.9b` 把第 1 章的启发式成本函数换成度量嵌入的**畸变**（价是一个可算的数）；`9.13b` **分辨率维数三分**（宏观维数／平均维数／熵维数，各由一条已证定理钉住）；`9.13c` 分辨成本的 **Θ(n log n)** 增长律与“预算”的对象级定义（Weisfeiler–Leman 维度，判定为 EXPTIME-完全）；`10.9b` **区分数**（多少类才够，带下界）；`10.9c` **一位的重量**（单位区分的杠杆与其上界）；`12.14b` **区分与二次型合在一处**的已证样本（定理 12.3：`Σ‖z(Aᵢ)‖² ≤ 9/(8π)`，极值为三个 2π/3 扇区）；`24.8b` **F 轴**（结论的适用范围：F1 每个 n 成立／F2 密度或速率／F3 仅渐进）。

3. **一处修订**：1.6 节由“第三种强度**唯一**的现代候选”改为“**两个**现代候选”，补入 Langlands（等价级、已证），并写明本书因此更保守。
