## 这本书在做什么

把"抽象统摄具体"写成可操作的方法（**压缩**），把它实现为一个形式框架（**演化区分系统**，EDS），在有限图上给出一个**完整、严格、可复现**的相变定理，并公开挂出一个**未解决的缺口**——分离曲率与 Gauss–Bonnet 定理之间的因子 **1/3**——作为可攻击的研究目标。

**一句话：** 它严格地解决了一个小问题，诚实地提出了一个大问题。

## 硬核：三个可独立验证的定理

从"硬核先行"的读法开始（见 `source/front_hardcore.html`）：

- **定理 A（图上相变）**：临界耦合 `β₁ = α/λₙ`、`β₂ = α/λ₂`，两阶段"局部先于全局"。
- **定理 B1（对称加权不可反转）**：任意正对称边权下 `β₁ ≤ β₂` 恒成立（400/400 数值验证）。
- **反例 B2（有向图可反转）**：6 顶点有向图上，全局模式先于局部模式增长（`β=0.5` vs `1.0`）。
- **定理 C（离散分离曲率）**：`κ_info(G) = Var(λ)/2`（从热核熵导出，精确恒等式）。
- **证伪 G4**：高维缺口因子 `f(n)=1/(2n+1)` 被球面计算证伪（`n=2` 得 `4π/3`）。
- **定理 B1′（Rayleigh 判据）**：对称 `L` 下最大特征值模式最大化 `R(v)=Σ(vᵤ−vᵥ)²/Σv²`；并报告否定性结果——非正规性/强连通性都不能预测反转。

## 定理 A 长什么样

在有限连通图 `G` 上，区分强度按 `Ḋ = (−αI + βL)D` 演化（`L` 为拉普拉斯矩阵）。两个临界耦合为

```
β₁ = α / λₙ      （最高频/局部模式先解锁）
β₂ = α / λ₂      （Fiedler/全局模式后解锁）
```

Petersen 图：`(0.200, 0.500)`；环 `C₁₀`：`(0.250, 2.618)`；完全图无中间相。**所有数字可用随书脚本复算。**


## 工程验证与形式化（附录 H—I）

为了回应“设立了高标准却只给出标签化任务”的批评，本书把短期任务落成实物：

- **附录 I．工程验证记录**：三个真正运行过的实验（含失败）：
  - `analysis/llm_activation_probe.py` — 合成 MLP（模加法）逐层测激活与有效秩；结果**混合**（一层支持耦合、一层反例）。
  - `analysis/orbifold_gap.py` — 9 例轨形计算，把 `χ(D)=χ(M)/3` **精确化为“当且仅当无奇异点”**（4 匹配 / 5 反例）。
  - `analysis/encoding_preservation.py` — 图论/线性代数/概率论保持结构；生成拓扑**反例**（8/29 个三元素拓扑）。
- **附录 H．形式化路线图**：`formalization/Distinction.lean` 未编译骨架 + 5 个引理的 PR 顺序 + 4 个瓶颈。**明确声明未编译、不声称已形式化。**
