## 这本书在做什么

本书的贡献是一次**归并**。作者初稿曾把框架写成三个原语——区分、曲率、演化；进一步的分析把它们收敛为两个更基本的词：**区分**与**对称双线性形式（二次型）**——「曲率」是形式谱的一个侧写，「演化」是形式谱上的线性 ODE。归并之后，语言更简洁、也更一般：协方差、Hessian、图拉普拉斯、内积、黎曼度量都是它的实例，谱定理、变分原理、极化恒等式是它自带的三套工具。

于是本书改换目标：不再宣布统一，而是把“区分”写成一套**语言描述**，并只在一个样本（图的拉普拉斯二次型）上把它完全兑现为一个可复算的两阶段相变定理。它同时登记两次不成立的推广（曲率、演化）与两次“换形式”的推广（辛：可计算；酉：新意有限）。

**一句话：** 它不再是“一个统一理论”，而是一套语言，加上一次诚实的归并。

## 定位：语言规范，而不是统一理论

这是一套**语言**——一组描述“对象如何被区分、区分结构如何用双线性形式度量、它的谱与变分性质是什么”的记号与约束——而不是一个宣称统一了数学的理论。两者要用不同的尺子量：理论看它证了多少条新定理；语言看它有没有被采用、有没有省下记号、有没有让跨领域迁移变得可读。本书把这个差别写成三条可反驳的验收标准（第 26.4.1 节）：

| 检验 | 问题 | 今天的状态 |
|---|---|---|
| **采纳** | 除作者外，是否真的有人用这套记号描述自己的对象？ | 未兑现 |
| **压缩** | 同一区分结构，用这套语言是否更短或更清楚？ | 部分（第 7—10 章四个样板） |
| **迁移** | 一个领域的区分命题能否在另一个领域被读懂、被检验？ | 部分（第 22 章 27 领域编码，含反例） |

把语言当成理论，会因为它今天不够格而否定它；把理论当成语言，会用普适性冒充解释力。本书在两者之间划一条线：**唯一被完全兑现的结果是图上相变定理；其余部分是语言的规格、样板与边界。**

## 样本：一个可完全兑现的定理（与一次归并）

从“先看可复算的事实”的读法开始（见 `source/front_hardcore.html`）：

- **定理 A（图上相变）**：临界耦合 `β₁ = α/λₙ`、`β₂ = α/λ₂`，两阶段“局部先于全局”。它是**图拉普拉斯二次型的谱分析**，属标准数学。
- **定理 B1（对称加权不可反转）**：任意正对称边权下 `β₁ ≤ β₂` 恒成立（400/400 数值验证）。
- **反例 B2（有向图可反转）**：6 顶点有向图上，全局模式先于局部模式增长（`β=0.5` vs `1.0`）。
- **定理 C（拉普拉斯谱方差）**：`κ_info(G) = Var(λ)/2`（从热核熵导出，精确恒等式）。**不再称为“分离曲率”**——它不是几何曲率 `R/6` 的离散化（第 19 章）。
- **证伪 G4**：高维缺口因子 `f(n)=1/(2n+1)` 被球面计算证伪（`n=2` 得 `4π/3`）。
- **定理 B1′（Rayleigh 判据）**：对称 `L` 下最大特征值模式最大化 `R(v)=Σ(vᵤ−vᵥ)²/Σv²`；并报告否定性结果——非正规性/强连通性都不能预测反转。

## 样本定理长什么样

在有限连通图 `G` 上，拉普拉斯二次型 `xᵀLx = Σ(xᵤ−xᵥ)²` 的矩阵为 `L`；区分强度按线性 ODE `Ḋ = (−αI + βL)D` 演化。两个临界耦合为

```
β₁ = α / λₙ      （最高频/局部模式先解锁）
β₂ = α / λ₂      （Fiedler/全局模式后解锁）
```

Petersen 图：`(0.200, 0.500)`；环 `C₁₀`：`(0.250, 2.618)`；完全图无中间相。**所有数字可用随书脚本复算。这是标准线性代数的应用，不是新框架。**

## 工程验证与形式化（附录 H—I）

为了回应“设立了高标准却只给出标签化任务”的批评，本书把短期任务落成实物：

- **附录 I．工程验证记录**：真正运行过的实验（含失败）：
  - `analysis/llm_activation_probe.py` — 合成 MLP（模加法）逐层测激活与有效秩；结果**混合**（一层支持耦合、一层反例）。
  - `analysis/orbifold_gap.py` — 9 例轨形计算，把 `χ(D)=χ(M)/3` 精确化为“当且仅当无奇异点”（4 匹配 / 5 反例）。现已归入“被归并的推广”：它是“把不同类型的量当成同一个”的产物。
  - `analysis/encoding_preservation.py` — 图论/线性代数/概率论保持结构；生成拓扑**反例**（8/29 个三元素拓扑）。
- **附录 H．形式化路线图**：`formalization/Distinction.lean` 未编译骨架 + 5 个引理的 PR 顺序 + 4 个瓶颈。**明确声明未编译、不声称已形式化。**
